Data Backup

Export the full library catalog, student roster and transaction history as a password-encrypted backup file, or restore from one or more previous encrypted backups at once. Only encrypted Stackroom backups can be imported — plain JSON files are rejected. Importing always merges into the current database: existing records are never overwritten or deleted, and any duplicate or invalid record found in a backup is skipped and listed in the report below.

Security

The admin PIN is verified locally against a PBKDF2 hash — the PIN itself is never stored. Repeated wrong attempts trigger a short lockout.

PIN recovery

A recovery code lets you reset the admin PIN locally, without a server and without touching any library data, if the PIN is ever forgotten. It's shown only once when generated — this app never displays it again.

Library Rules · Fine & Return Policy

Grace Period and Fine Amount are used everywhere a loan's status is shown — Dashboard, Issued, Overdue, Return, Returned, and Transactions. Changing the Fine Amount immediately updates the fine shown on every active overdue loan; already-returned loans keep the fine that was calculated at the time they were returned. Changing either setting requires the admin PIN.

Grace Period: number of days after the due date during which no fine is charged. Fine Amount: fine charged per day after the Grace Period ends.

Danger Zone

Master Reset permanently erases the book registry, student roster, transaction history, Fine/Grace settings and audit history, returning Stackroom to an empty library. It does not erase your admin PIN or recovery code, and you will stay logged in. This cannot be undone.
